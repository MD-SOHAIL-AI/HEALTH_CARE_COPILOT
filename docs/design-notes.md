# Design notes

## Inspo MCP

Configured via:

```bash
npx -y inspo-mcp install
```

Hosted endpoint: https://inspomcp.dev/api/mcp  
Restart Cursor to load the `inspo` MCP server, then use `recommend` / `get_design_system` for further refinements.

## Applied direction (calm health dashboard)

Inspired by the brief “calm, trustworthy personal health dashboard”:

- **Palette:** teal brand (`#1b767c`) on soft mint surfaces, slate ink
- **Type:** Fraunces (display) + Inter (UI)
- **Shape:** large radii (xl / 2xl), light elevation, generous whitespace
- **Trust cues:** persistent amber disclaimer banner, confidence badges, provenance links to source documents
